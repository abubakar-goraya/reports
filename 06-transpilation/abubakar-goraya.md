# TRANSPILATION

## 1. Definition

#### History
Transpilation comes from words translate and compilation. It first emerged between the 1960s and 1970s with tools for translating languages like COBOL , assembly , etc.

Transpilation is the type of compilation that takes high-level source code and converts it into another high-level source code while keeping the abstraction level same (not changing the logic of code, mostly changing just the syntax). It is also called source to source compilation.

Unlike compilation, it does not convert human read-able source code into machine read-able code , rather it transpiles HLL source code into another HLL source code.
